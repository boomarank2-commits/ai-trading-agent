# Verworfene Strategie-Snapshots

Dieser Ordner ist ausschließlich ein unveränderliches Forschungsarchiv.
Dateien hier werden weder vom Paperbot noch vom Backtest-UI als aktive
Strategien geladen. Die produktive Dry-run-Strategie liegt ausschließlich
unter `runtime/user_data/strategies/CompressionBreakout250.py`.

Die Snapshots bleiben erhalten, damit ihre registrierten Quell-Hashes und
bereits entschiedenen Tests später überprüfbar sind. Sie dürfen nicht in den
aktiven Strategieordner kopiert, stillschweigend verändert oder mit identischem
Test-Fingerprint erneut ausgeführt werden. Eine neue Hypothese braucht eine
neue Version, Vorregistrierung und einen materiell anderen Fingerabdruck.
