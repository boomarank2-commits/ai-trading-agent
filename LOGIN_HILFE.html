Kennst du dein Passwort nicht?

Auf einem frisch heruntergeladenen Bot erzeugt STARTBOT.bat beim ersten Start ein zufaelliges lokales Passwort, zeigt es aus Sicherheitsgruenden aber nicht im Startfenster an.

Fuehre PASSWORT_AENDERN.bat aus, setze ein eigenes lokales Passwort und starte den Bot danach neu. Das Passwort wird nicht im Repository gespeichert.

Wenn du bereits ein eigenes lokales Passwort gesetzt hast, gilt stattdessen dieses eigene Passwort.

Nach der ersten erfolgreichen Anmeldung:
  1. Bot spaeter sauber mit Strg+C beenden.
  2. PASSWORT_AENDERN.bat im Bot-Ordner doppelklicken.
  3. Eigenes Passwort eingeben.
  4. STARTBOT.bat erneut starten. Erst dann ist das neue Passwort aktiv.
Das neue Passwort wird nur auf diesem Rechner gespeichert und nicht zu GitHub hochgeladen.
Eigenes Passwort vergessen?
Fuer diesen kleinen privaten Testbot gibt es bewusst keinen Online-Reset-Dienst. Mit PASSWORT_AENDERN.bat setzt du lokal ein neues Passwort; es wird nach dem naechsten sauberen Botstart aktiv.
