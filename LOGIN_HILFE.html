Kennst du dein Passwort nicht?

STARTBOT zeigt das aktuell gueltige lokale Passwort bei jedem Start genau einmal im Konsolenfenster an. Beim ersten Start wird es zuvor zufaellig erzeugt.

Bitte dieses Passwort notieren. Es wird unter %LOCALAPPDATA%\DaviddTech\AiTradingAgent\auth\frequi-v2.json mit Windows-DPAPI verschluesselt, an deinen Windows-Benutzer gebunden und durch eine exklusive Datei-ACL geschuetzt.

Wenn du bereits ein eigenes lokales Passwort gesetzt hast, gilt dieses eigene Passwort.

Optional nach der ersten erfolgreichen Anmeldung:
  1. Bot spaeter sauber mit Strg+C beenden.
  2. PASSWORT_AENDERN.bat im Bot-Ordner doppelklicken.
  3. Eigenes Passwort eingeben.
  4. STARTBOT.bat erneut starten. Erst dann ist das neue Passwort aktiv.
Das neue Passwort wird nur auf diesem Rechner gespeichert und nicht zu GitHub hochgeladen.
Eigenes Passwort vergessen?
Fuer diesen kleinen privaten Testbot gibt es bewusst keinen Online-Reset-Dienst. Unter demselben Windows-Benutzer kann mit PASSWORT_AENDERN.bat jederzeit ein neues lokales Passwort gesetzt werden.
